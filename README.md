# 🪐 Автономный Telegram-бот Персонального Гороскопа

Полностью автономный Telegram-бот для ежедневной рассылки персонализированного астрологического прогноза на базе новейших моделей **Google AI (Gemini 3.7 / 2.5 Flash)** и космических иллюстраций.

Бот работает **24/7 абсолютно бесплатно** в облаке **GitHub Actions** по расписанию (каждое утро в 03:33 UTC). Ваш компьютер держать включенным не нужно!

---

## 🌟 Ключевые возможности

- 🧠 **Автопоиск моделей Google AI (Auto-Discovery)**: скрипт автоматически находит и использует новейшую Flash-модель (Gemini 3.7 Flash, 2.5 Flash и др.).
- 🛡️ **Отказоустойчивость (Auto-Fallback)**: при временной перегрузке модели бот автоматически пробует резервные варианты.
- 🎯 **Индивидуальный расчет натальной карты**: прогноз строится по вашей точной дате рождения, времени и городу (из `config.json`).
- 🎨 **Космическая иллюстрация дня**: генерация тематической картины каждого дня с резервным переключением на локальную обложку.
- 📨 **Гарантированная доставка в Telegram**: интеллектуальное разделение длинных текстов по абзацам и двухуровневая защита HTML-разметки (при ошибке Telegram бот мгновенно отправляет чистый текст).
- ⚙️ **Простота настройки**: все персональные данные меняются в одном файле `config.json` без правок программного кода.

## 📁 Структура проекта

```text
├── .github/workflows/
│   └── daily_horoscope.yml   # Расписание запуска в облаке GitHub Actions (03:33 UTC)
├── assets/
│   └── default_cover.png     # Резервная графическая обложка

```

## 🚀 Пошаговая инструкция по настройке

### Шаг 1. Получение бесплатных ключей

#### 1. Ключ Google AI Studio (Gemini):
1. Перейдите на сайт [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Войдите через ваш Google-аккаунт и нажмите **Create API key**.
3. Скопируйте созданный ключ (начинается на `AIzaSy...`).

#### 2. Токен Telegram-бота:
1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте подсказкам (задайте имя и username).
3. Скопируйте выданный токен (например: `1234567890:ABCdef...`).
4. Нажмите `/start` в диалоге со своим созданным ботом.

#### 3. ID вашего чата или канала:
- **Для личных сообщений**: откройте бота [@userinfobot](https://t.me/userinfobot) и скопируйте ваш цифровой `Id` (например, `123456789`).
- **Для канала/группы**: добавьте вашего бота администратором в канал. ID канала обычно начинается с `-100...`.

---

### Шаг 2. Настройка персональных данных (`config.json`)

Откройте файл `config.json` и укажите свои данные:

```json
{
  "user_profile": {
    "name": "Иван",
    "birth_date": "15.04.1988",
    "birth_time": "14:30",
    "birth_city": "Москва",
    "is_general": false
  },
  "bot_settings": {
    "send_image": true,
    "timezone": "Europe/Moscow"
  }
}
```

> 💡 **Подсказка**: Если вы хотите получать общий ежедневный гороскоп без привязки к дате рождения, оставьте `birth_date: ""` или укажите `"is_general": true`.

---

### Шаг 3. Локальное тестирование на компьютере

1. Создайте файл `.env` в папке проекта (на основе `.env.example`) и вставьте ваши ключи:
   ```env
   GEMINI_API_KEY=ваш_ключ_google
   TELEGRAM_TOKEN=ваш_токен_бота
   TELEGRAM_CHAT_ID=ваш_chat_id
   ```

2. Установите зависимость:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите удобное меню тестирования:
   ```bash
   python test_local.py
   ```
   В меню вы сможете:
   - Проверить соединение с серверами Google и Telegram (пункт 1).
   - Посмотреть список найденных новейших моделей Google AI (пункт 2).
   - Сгенерировать пробный текст гороскопа в консоль (пункт 3).
   - Сделать полный тестовый запуск с отправкой в Telegram (пункт 5).

---

### Шаг 4. Настройка 24/7 рассылки в GitHub Actions

Чтобы бот работал сам по себе каждый день в облаке:

1. Загрузите проект в ваш репозиторий на **GitHub**.
2. В репозитории перейдите в **Settings** ➔ **Secrets and variables** ➔ **Actions**.
3. Нажмите кнопку **New repository secret** и добавьте 3 секрета:
   - `GEMINI_API_KEY` — ваш ключ Google AI.
   - `TELEGRAM_TOKEN` — токен Telegram-бота.
   - `TELEGRAM_CHAT_ID` — ваш Chat ID.
4. Перейдите во вкладку **Actions** в GitHub:
   - Выберите рабочий процесс **Daily Horoscope Bot**.
   - Нажмите кнопку **Run workflow**, чтобы протестировать облачный запуск вручную.
5. Готово! Теперь бот будет автоматически просыпаться каждое утро в **03:33 UTC** и присылать свежий персональный прогноз дня! ✨
