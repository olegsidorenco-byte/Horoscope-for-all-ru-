# 🪐 Автономный Telegram-бот Персонального Гороскопа

Полностью автономный Telegram-бот для ежедневной потемной рассылки структурированного астрологического прогноза на базе новейших моделей **Google AI (Gemini 3.7 / 2.5 Flash)**.

Бот работает **24/7 абсолютно бесплатно** в облаке **GitHub Actions** по расписанию (каждое утро в **03:10 UTC** — по расписанию на 23 минуты раньше прежнего времени).

---

## 🌟 Ключевые возможности

- ☀️ **Теплое утреннее приветствие и обобщенный прогноз**: каждый день начинается с разнообразного приветствия с гармоничными эмодзи (например: `☀️🌸🌿`, `🌅✨☕`, `🌺🕊️🌾`) и емкого астрологического фона дня в 2–3 предложениях.
- 📑 **Потемная разбивка на отдельные сообщения**: прогноз автоматически разделяется на самостоятельные темы и отправляется серией последовательных аккуратных сообщений в Telegram:
  1. 🌅 *Приветствие и обобщенный прогноз дня*
  2. 🪐 *Влияние планет на сегодня*
  3. 💼 *Работа, бизнес и финансы*
  4. ❤️ *Личные отношения и общение*
  5. 🌿 *Здоровье и тонус*
  6. 💡 *Добрый совет на сегодня*
  7. ✨ *Пожелание на сегодня*
- 🛡️ **Продвинутая защита от спама и комфортная доставка**:
  - Комфортный перерыв (по умолчанию 10 минут) между отправкой тематических сообщений, чтобы не перегружать пользователя («эффект спама») и обеспечить удобное чтение.
  - Индикация действия «печатает...» (`typing`) перед отправкой каждой темы.
  - Автоматическая обработка ошибки `429 Too Many Requests` (считывание `retry_after` и автоповтор).
  - Двухуровневая защита HTML-разметки (при ошибке Telegram бот мгновенно отправляет чистый текст).
- 🧠 **Автопоиск моделей Google AI (Auto-Discovery)**: скрипт автоматически находит и использует самую быструю и актуальную Flash-модель (Gemini 3.7 Flash, 2.5 Flash и др.).
- 🎯 **Индивидуальный расчет натальной карты**: прогноз строится по вашей дате рождения, времени и городу (из `config.json`), либо формирует общий астрологический прогноз.
- ⚙️ **Простота настройки**: все данные и интервалы меняются в `config.json` без правок программного кода.

## 📁 Структура проекта

```text
├── .github/workflows/
│   └── daily_horoscope.yml   # Расписание запуска в облаке GitHub Actions (03:10 UTC)
├── config.json               # Ваши персональные данные и интервалы (дата, город, имя, пауза)
├── config_loader.py          # Загрузчик настроек и безопасных токенов
├── ai_service.py             # Модуль Google AI (генерация, натал, разбивка по темам)
├── telegram_service.py       # Модуль доставки в Telegram (интервалы, typing, rate-limiting)
├── main.py                   # Главный координатор рассылки
├── test_local.py             # Интерактивное меню для локальной проверки
├── requirements.txt          # Зависимости проекта (requests)
└── .env.example              # Пример файла с секретными ключами
```

## 🚀 Пошаговая инструкция по настройке

### Шаг 1. Получение бесплатных ключей

#### 1. Ключ Google AI Studio (Gemini):
1. Перейдите на сайт [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Войдите через ваш Google-аккаунт и нажмите **Create API key**.
3. Скопируйте созданный ключ (начинается на `AIzaSy...`).

#### 2. Токен Telegram-бота:
1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте подсказкам (задайте имя и username).
3. Скопируйте выданный токен (например: `1234567890:ABCdef...`).
4. Нажмите `/start` в диалоге со своим созданным ботом.

#### 3. ID вашего чата или канала:
- **Для личных сообщений**: откройте бота [@userinfobot](https://t.me/userinfobot) и скопируйте ваш цифровой `Id` (например, `123456789`).
- **Для канала/группы**: добавьте вашего бота администратором в канал. ID канала обычно начинается с `-100...`.

---

### Шаг 2. Настройка персональных данных (`config.json`)

Откройте файл `config.json` и укажите свои данные:

```json
{
  "user_profile": {
    "name": "Иван",
    "birth_date": "15.04.1988",
    "birth_time": "14:30",
    "birth_city": "Москва",
    "is_general": false
  },
  "bot_settings": {
    "send_image": false,
    "delay_between_messages_minutes": 10,
    "timezone": "Europe/Moscow"
  }
}
```

> 💡 **Подсказка**: Параметр `delay_between_messages_minutes` регулирует паузу (в минутах) между доставкой каждой темы. По умолчанию установлено 10 минут.

---

### Шаг 3. Локальное тестирование на компьютере

1. Создайте файл `.env` в папке проекта (на основе `.env.example`) и вставьте ваши ключи:
   ```env
   GEMINI_API_KEY=ваш_ключ_google
   TELEGRAM_TOKEN=ваш_токен_бота
   TELEGRAM_CHAT_ID=ваш_chat_id
   ```

2. Установите зависимость:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите удобное меню тестирования:
   ```bash
   python test_local.py
   ```
   В меню вы сможете:
   - Проверить соединение с серверами Google и Telegram (пункт 1).
   - Посмотреть список найденных новейших моделей Google AI (пункт 2).
   - Сгенерировать прогноз и посмотреть разбивку по темам в консоли (пункт 3).
   - Выполнить тестовую потемную доставку в Telegram (пункт 4).

---

### Шаг 4. Настройка 24/7 рассылки в GitHub Actions

Чтобы бот работал сам по себе каждый день в облаке:

1. Загрузите проект в ваш репозиторий на **GitHub**.
2. В репозитории перейдите в **Settings** ➔ **Secrets and variables** ➔ **Actions**.
3. Нажмите кнопку **New repository secret** и добавьте 3 секрета:
   - `GEMINI_API_KEY` — ваш ключ Google AI.
   - `TELEGRAM_TOKEN` — токен Telegram-бота.
   - `TELEGRAM_CHAT_ID` — ваш Chat ID.
4. Перейдите во вкладку **Actions** в GitHub:
   - Выберите рабочий процесс **Daily Horoscope Bot**.
   - Нажмите кнопку **Run workflow**, чтобы протестировать облачный запуск вручную.
5. Готово! Теперь бот будет автоматически отправлять серию тематических сообщений каждое утро в **03:10 UTC**! ✨
